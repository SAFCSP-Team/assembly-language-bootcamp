# Input and Output

Assembly language is the closest human-readable representation of machine code. It provides direct control over a computer's hardware. It is often used in bootloaders and operating systems. System calls in Assembly allow programs to request services from the operating system, such as input/output, process management, and file operations.


## What Are System Calls?

System calls are **requests from a user program to the operating system kernel** to perform tasks the program cannot do directly (such as accessing hardware, files, or memory management). In x86-32 Linux assembly, you call the kernel using the `int 0x80` instruction.


## How System Calls Work in x86-32

1. **Load the syscall number** into the `EAX` register.
2. **Load arguments** into registers (`EBX`, `ECX`, `EDX`, `ESI`, `EDI`, `EBP`) as needed.
3. **Trigger the system call** via the `int 0x80` instruction.
4. **Read the return value** from `EAX`.

**Negative return values** indicate errors (the negative errno value).


## System Call Arguments and Registers

| Register | Purpose                |
|----------|------------------------|
| `EAX`    | System call number     |
| `EBX`    | 1st argument           |
| `ECX`    | 2nd argument           |
| `EDX`    | 3rd argument           |
| `ESI`    | 4th argument           |
| `EDI`    | 5th argument           |
| `EBP`    | 6th argument           |


## Most Common System Calls (x86-32 Linux)

| Name     | Syscall # | Usage Example                      |
|----------|-----------|------------------------------------|
| `exit`   | 1         | End the program                    |
| `read`   | 3         | Read from file or input            |
| `write`  | 4         | Write to file or output            |
| `open`   | 5         | Open a file                        |
| `close`  | 6         | Close an open file descriptor      |
| `execve` | 11        | Run a new program                  |
| `fork`   | 2         | Create a child process             |
| `getpid` | 20        | Get process ID                     |

See the full list with:  
```sh
man 2 syscalls
man 2 <syscall_name>
```

## Input and Output (I/O)

Input and Output (I/O) in assembly language involves interacting with external devices like keyboards, monitors, printers, etc. I/O is typically managed using system calls (for high-level OS interaction) or port-mapped I/O (for direct hardware communication).

## Methods of I/O
### **1. System Calls**
Most modern assembly programs interact with the operating system to handle I/O, such as reading input from a keyboard or writing output to the console or screen.

**Examples:**
- A program prints "Hello, World!" and then exit.
```asm
section .data
    msg db 'Hello, World!', 0xA   ; 0xA = newline
    len equ $ - msg               ; length of our message

section .text
    global _start

_start:
    ; write(1, msg, len)
    mov eax, 4         ; syscall #4 = sys_write
    mov ebx, 1         ; file descriptor 1 = stdout
    mov ecx, msg       ; pointer to message
    mov edx, len       ; length of message
    int 0x80           ; make the syscall

    ; exit(0)
    mov eax, 1         ; syscall #1 = sys_exit
    xor ebx, ebx       ; return code 0
    int 0x80           ; make the syscall
```

- msg contains the string "Hello, World!" followed by a newline (0xA).
- len calculates the length of the string automatically.

**Output:**
```asm
Hello, World!
```

- This program reads up to 32 characters from stdin (keyboard) and echoes them back to the screen.

```asm
section .bss
    buffer resb 32                ; Reserve 32 bytes for input

section .text
    global _start

_start:
    ; read(0, buffer, 32)
    mov eax, 3         ; syscall #3 = sys_read
    mov ebx, 0         ; file descriptor 0 = stdin
    mov ecx, buffer    ; pointer to buffer
    mov edx, 32        ; number of bytes
    int 0x80           ; make the syscall

    mov edx, eax       ; actual bytes read (eax)
    ; write(1, buffer, edx)
    mov eax, 4         ; syscall #4 = sys_write
    mov ebx, 1         ; file descriptor 1 = stdout
    mov ecx, buffer    ; pointer to buffer
    int 0x80           ; make the syscall

    ; exit(0)
    mov eax, 1         ; syscall #1 = sys_exit
    xor ebx, ebx       ; return code 0
    int 0x80

```
- Section .bss: buffer: Reserves 32 bytes to store user input.

**Output**
```asm
Input: Hello, NASM!
Output: Hello, NASM!
```
> [!important]
> System calls vary based on the operating system (e.g., Linux, Windows).

### 2. **Port-Mapped I/O (Direct Hardware Access)**

I/O ports are used to communicate directly with hardware devices. This involves instructions like `IN` and `OUT` to read from or write to specific ports.
This method is more common in low-level embedded systems or older computer systems.

**Examples:**
Reading and Writing Using Ports
```asm
mov dx, 0x60      ; Port address (e.g., keyboard data port)
in  al, dx        ; Read a byte from the port into AL
mov dx, 0x64      ; Port address (e.g., keyboard command port)
out dx, al        ; Write the byte from AL to the port
```

## File Operations

File operations in x86-32 assembly involve using system calls like `open`, `read`, `write`, and `close`. These syscalls allow you to interact with files on the filesystem.

### Common File-Related Syscalls

| Syscall Name | Syscall # | Purpose                          |
|--------------|-----------|----------------------------------|
| `open`       | 5         | Open a file                     |
| `read`       | 3         | Read data from a file           |
| `write`      | 4         | Write data to a file            |
| `close`      | 6         | Close an open file descriptor   |

 
Examples:


This program writes the string "Hello, File!" to a file named `output.txt`.

```asm
section .data
    filename db 'output.txt', 0      ; File name (null-terminated)
    message db 'Hello, File!', 0xA  ; Message to write (with newline)
    len equ $ - message             ; Length of the message

section .text
    global _start

_start:
    ; open(filename, O_WRONLY | O_CREAT, 0644)
    mov eax, 5         ; syscall #5 = sys_open
    mov ebx, filename  ; Pointer to file name
    mov ecx, 0x401     ; Flags: O_WRONLY | O_CREAT (octal 401)
    mov edx, 0644      ; Permissions: rw-r--r-- (octal 644)
    int 0x80           ; Make the syscall
    mov ebx, eax       ; Save file descriptor in EBX

    ; write(fd, message, len)
    mov eax, 4         ; syscall #4 = sys_write
    mov ecx, message   ; Pointer to message
    mov edx, len       ; Length of the message
    int 0x80           ; Make the syscall

    ; close(fd)
    mov eax, 6         ; syscall #6 = sys_close
    int 0x80           ; Make the syscall

    ; exit(0)
    mov eax, 1         ; syscall #1 = sys_exit
    xor ebx, ebx       ; Return code 0
    int 0x80
```



This program reads the contents of a file named `input.txt` and displays it on the screen.

```asm
section .data
    filename db 'input.txt', 0      ; File name (null-terminated)

section .bss
    buffer resb 64                 ; Reserve 64 bytes for file data

section .text
    global _start

_start:
    ; open(filename, O_RDONLY)
    mov eax, 5         ; syscall #5 = sys_open
    mov ebx, filename  ; Pointer to file name
    xor ecx, ecx       ; Flags: O_RDONLY (0)
    int 0x80           ; Make the syscall
    mov ebx, eax       ; Save file descriptor in EBX

    ; read(fd, buffer, 64)
    mov eax, 3         ; syscall #3 = sys_read
    mov ecx, buffer    ; Pointer to buffer
    mov edx, 64        ; Number of bytes to read
    int 0x80           ; Make the syscall

    ; write(1, buffer, eax)
    mov eax, 4         ; syscall #4 = sys_write
    mov ebx, 1         ; File descriptor 1 = stdout
    int 0x80           ; Make the syscall

    ; close(fd)
    mov eax, 6         ; syscall #6 = sys_close
    int 0x80           ; Make the syscall

    ; exit(0)
    mov eax, 1         ; syscall #1 = sys_exit
    xor ebx, ebx       ; Return code 0
    int 0x80
```
