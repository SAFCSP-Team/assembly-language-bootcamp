
# Machine layout
The machine layout is the physical and logical organization of a computer's components. Assembly language directly interacts with these components to execute instructions.



The Key Components in machine layout are:

1. Central Processing Unit (CPU)
2. Memory (RAM)
3. I/O Devices
4. Bus Systems

### Central Processing Unit (CPU)

The CPU is like the computer's brain, where all assembly instructions are executed. It consists of:
- `Registers`: used to hold data, instructions, or addresses temporarily.
- `Arithmetic Logic Unit (ALU)`: performs arithmetic (e.g., addition, subtraction) and logical operations (e.g., AND, OR).
- `Control Unit`: decodes assembly instructions into signals that guide the CPU's operations.


### Memory (RAM)

RAM stores data and instructions temporarily during execution.

The Structure of the RAM is:

Divided into segments for organization:
- `Code Segment`: Stores program instructions.
- `Data Segment`: Holds variables and constants.
- `Heap Segment`: Used for dynamic memory allocation during program execution.
- `Stack Segment`: Manages function calls and temporary data.


### Input/Output (I/O) Devices
- Input Devices: Provide data to the system, like Keyboards, mic, etc. 
- Output Devices: Display or output processed data, like Monitors, printers, etc.


### Bus Systems
- `Data Bus`: Transfers data between the CPU, memory, and I/O devices.
- `Address Bus`: Carries the memory or I/O address being accessed.
- `Control Bus`: Sends control signals to various components of the computer system (e.g., read/write, interrupts).

### How the execution flows in the machine layout

When an assembly program runs, here’s how the machine components interact:

1. `Fetch`: the CPU fetches the next instruction from the memory address pointed to by the Instruction Pointer(IP).
2. `Decode`: the Control Unit decodes the instruction into signals, identifies the operation (e.g., MOV, ADD, etc.), and operands (registers or memory).
3. `Execute`: the ALU performs operations on data in registers (e.g., adding two numbers), and data is moved between the CPU and memory as needed.
4. `Store`: if required, results are written back to memory or registers.
