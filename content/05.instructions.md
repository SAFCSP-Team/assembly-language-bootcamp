# Assembly Language Instructions

An **instruction** in assembly language is a fundamental command that tells your computer’s processor exactly what to do. These instructions are the building blocks of all computer programs.

## What Are Instructions?
In assembly language, an **instruction** is a single operation for the CPU to perform. Each instruction is translated directly into a machine code operation. 

**Instructions can:**
- Manipulate data
- Control program flow
- Interact with hardware

### Basic Structure

Each instruction generally has two main parts:
- **Mnemonic**: The short name for the operation (e.g., `MOV` for *move*, `SUB` for *subtraction*).
- **Operands**: The values or locations the instruction works on (e.g., registers, memory addresses, constants)


> [!IMPORTANT]
> Assembly mnemonics are **not case-sensitive**: `MOV` and `mov` are the same.



## Instruction Syntax

Assembly instructions generally follow this format:

```
MNEMONIC  OPERAND1, OPERAND2   ; Optional Comment
```
- **Mnemonic/Operation/Opcode**: The command you want the computer to perform (for example, `MOV` to move data, `ADD` to add numbers).
- **OPERANDS:** The data or locations involved (e.g., registers, memory addresses, constants). The first operand is generally the **destination**, and the second is the **source**.
- **Comment**: Begins with `;` and is ignored by the assembler. 


#### Example
Suppose your data section is:
```asm
.data
a   dw 10       ; 2-byte variable 'a' initialized to 10
b   dw 0        ; 2-byte variable 'b' initialized to 0
```
You can use:

```asm
MOV  b, a     ; Copy value of 'a' into 'b'
```
#### Syntax Guidelines
- Only **one instruction per line**.
- Use **commas** to separate the operands.
- Whitespace (tabs or spaces) is used for readability.
- Use **comments** to document your code.
- Directives (such as `.data` or `.code`) are not instructions, they guide the assembler, not the CPU.


## Registers
**Registers** are small, fast storage locations within the central processing unit (CPU) that are used in nearly every assembly instruction. You can think of them as specialized "containers" that the processor uses to temporarily hold data while performing calculations and moving information.

### Common 32-bit x86 Registers

In 32-bit assembly (like x86), some commonly used registers are:

| Name | Typical Use          | Description                                |
|------|---------------------|--------------------------------------------|
| EAX  | Accumulator         | General-purpose, often used for results    |
| EBX  | Base                | General-purpose or addressing              |
| ECX  | Counter             | Often used for loops/counting              |
| EDX  | Data                | General-purpose or data operations         |
| ESI  | Source Index        | Used in memory copy operations             |
| EDI  | Destination Index   | Used in memory copy operations             |
| ESP  | Stack Pointer       | Points to top of the stack                 |
| EBP  | Base Pointer        | Used for stack frames                      |

- Registers are named beginning with **E** for “extended” (because they hold 32 bits).
- Each register can hold just one value at a time, like a variable in your program.


#### Example
```asm
MOV EAX, 10    ; Put the value 10 into EAX register
MOV ECX, EAX   ; Copy the value from EAX into ECX register
```
After these instructions, both EAX and ECX contain the value 10.


## Common Assembly Instructions

### Data Movement Instructions

These copy or transfer data between registers, memory, or constants.

#### `MOV` : Move Data

Copies data from the source to the destination.

```asm
MOV AX, BX       ; Copy BX to AX
MOV AL, 1        ; Place the value 1 in the AL register
MOV [VAR], AL    ; Store AL's value at memory location VAR
MOV CL, [COUNT]  ; Load value at COUNT into register CL
```

#### `LEA` : Load Effective Address

Loads a memory address (not value) into a register.

```asm
LEA SI, [myArray]  ; SI now holds the address of 'myArray'
```

#### `XCHG` : Exchange

Swaps the contents of two operands (register–register or register–memory).

```asm
XCHG AL, AH        ; Swap values of AL and AH
```

**Rules:**
- Both operands cannot be memory addresses
- Operand sizes must match


###Arithmetic Instructions

Used for arithmetic calculations in your programs.

#### `ADD`: Add two values 

Adds source to destination.

```asm
ADD AX, 10    ; AX = AX + 10
```

#### `SUB` : Subtract two values

Subtracts source from destination.

```asm
SUB BX, AX    ; BX = BX - AX
```

#### `INC` : Increment the value 

Increases destination by 1.

```asm
INC CX        ; CX = CX + 1
```

#### `DEC` : Decrement the value 

Decreases destination by 1.

```asm
DEC DX        ; DX = DX - 1
```

#### `MUL` / `IMUL`, `DIV` / `IDIV` — Multiply and Divide

Multiply and divide values. Use `MUL`/`DIV` for unsigned, `IMUL`/`IDIV` for signed.

```asm
MUL BX        ; AX = AX * BX (unsigned multiply)
IMUL DX       ; AX = AX * DX (signed multiply)
DIV CL        ; AX ÷ CL (quotient in AL, remainder in AH)
```


### Logical Instructions

Operate on bits for logic processing.

#### `AND` : Bitwise AND

```asm
AND AX, 0FFH   ; Mask AX: clear high byte
```

#### `OR` : Bitwise OR

```asm
OR AL, BL      ; Set bits in AL according to BL
```

#### `XOR` : Bitwise Exclusive OR

```asm
XOR BX, BX     ; Quickly zeroes BX
```

#### `NOT` : Bitwise NOT

```asm
NOT CX         ; Invert all bits in CX
```


### Comparison Instruction

#### `CMP` : Compare two values

Subtracts source from destination, sets status flags (no result is stored directly).

```asm
CMP AX, BX     ; Sets flags as if AX - BX
```


## Instruction Encoding 
Assemblers convert assembly instructions into **machine code** in binary, so the CPU can execute them. This process is called **instruction encoding**.


**Key encoding concepts:**
- **Opcode** (operation code): Tells the CPU which action to perform.
- **Operands:** Specify data locations, registers, or constants.
- **Instruction length:** A single assembly instruction can take up multiple bytes of machine code, depending on its complexity, operand types, and addressing modes.


**Encoding Example:**

| Assembly         | Machine Code (x86) | Meaning                         |
|------------------|-------------------|---------------------------------|
| `MOV AX, BX`     | `89 D8`           | Move contents of BX into AX     |
| `ADD AL, 1`      | `04 01`           | Add 1 to the AL register        |

> [!Note]
> While you usually don't write machine code directly, understanding encoding helps with debugging, and performance.
